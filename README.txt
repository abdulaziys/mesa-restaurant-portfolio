MESA — RESTAURANT WEBSITE PORTFOLIO CONCEPT
===========================================

PROJECT STRUCTURE
- index.html
- css/style.css
- js/script.js

HOW TO OPEN IN ACODE (ANDROID)
1. Extract the ZIP into a folder named restaurant-portfolio.
2. Open Acode > Open Folder and select restaurant-portfolio.
3. Open index.html and use Preview (or open the file in your browser).
4. Keep the css and js folders beside index.html. Do not rename them.
5. Internet is needed for Google Fonts and the remote food photos.

CUSTOMIZE BEFORE PUBLISHING
- Replace MESA name, text, address, phone, email and opening hours.
- Replace sample prices and menu items with real information.
- Update image URLs with photos you have permission to use.
- The mailto button is a demo enquiry link, not a working booking system.
- The page currently has no backend, online ordering, payment, or database.

PORTFOLIO DISCLOSURE
This is a self-initiated concept project, not a commissioned client website.
Label it as "Concept Project" in your portfolio.
